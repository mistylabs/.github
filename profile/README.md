# Misty

Misty is a local-first, zero-knowledge notes and publishing platform.

It connects your personal vault to the cloud in a way that keeps ownership where it belongs — with you.  
Write privately, sync securely, share selectively, and publish when you choose.

Misty is built around three ideas:

- Your notes should live with you, not inside a platform  
- Privacy must be the default, not an option  
- Tools should feel like companions, not collectors

Everything is end-to-end encrypted.  
Even the server cannot read your private content.

Misty is currently in active development.

A living manifesto and vision for the project lives at:  
https://misty.p8labs.tech

Misty exists to make thinking feel safe again.
